You multiply by each group's fraction because you want **the average uncertainty remaining for an original example**. A group containing more examples should contribute more to that average.

Here, entropy measures how uncertain an example's label is within its group. Suppose a split divides 100 examples into:

| Group | Examples | Labels | Entropy |
| --- | ---: | --- | ---: |
| A | 90 | All the same | 0 bits |
| B | 10 | Half one label, half another | 1 bit |

Zero means the label is certain. One bit here is the uncertainty of a fair yes/no choice.

Pick one of the original 100 examples at random. It has a 90% chance of belonging to A, where there is no label uncertainty, and a 10% chance of belonging to B, where there is one bit. So the average remaining uncertainty is:

\[
\frac{90}{100}\times 0 + \frac{10}{100}\times 1
= 0.1\text{ bits per example}.
\]

A plain average, \((0+1)/2=0.5\), would give the 10-example group as much influence as the 90-example group. **Weighting by group size makes every example count equally.**

For a decision-tree split, the denominator is the number of examples in the group being split—the current node—not necessarily the entire training dataset.
