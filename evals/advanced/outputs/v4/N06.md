The key is that **“95%” describes how reliably the method produces intervals that contain the true value**.

Imagine you want the average height of all the trees in a forest. That average is one unknown number. You measure a random sample of trees and calculate an interval.

Suppose the true average is actually 10 metres, though you don't know it:

- One sample might give an interval of **9.6–10.4 metres**. This contains the true average.
- Another sample might give **10.1–10.9 metres**. This misses it.

The forest's true average stays the same. The interval changes because you sampled different trees. Over many repetitions, a method that produces 95% confidence intervals would include the true average about 95% of the time, provided its assumptions hold.

Once you have your particular interval, the sampling is finished. Your interval either contains the true average or misses it, and you usually don't know which. The 95% tells you the method's long-run success rate; it doesn't calculate a probability for the unknown average to be inside that particular range.

You can read a 95% confidence interval as: **“This range was produced by a method that captures the true value in about 95% of repeated samples.”** Assigning probabilities directly to the unknown average would require additional assumptions and a different statistical calculation.
