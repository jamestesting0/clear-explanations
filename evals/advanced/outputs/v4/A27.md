The machine's state can change between readings, so each minute requires two steps: first predict through the state transition, then update that prediction using the new reading. The resulting degradation probabilities support **no inspection after minute 2** and **inspection after minute 3** under the stated current-minute costs.

## Predict, then update

Let \(p_t\) be the probability of degradation at minute \(t\) after using observations through that minute. Let \(q_t\) be the probability at minute \(t\) before using that minute's reading. Start with \(p_0=0.10\).

Because the state changes before each observation,

\[
q_t=0.80p_{t-1}+0.05(1-p_{t-1})
    =0.05+0.75p_{t-1}.
\]

The first term covers a previously degraded machine remaining degraded; the second covers a previously normal machine becoming degraded. This transition applies before minute 1 as well as before later readings. [A27-STATE]

For an alarm, the updated probability is

\[
p_t=\frac{0.90q_t}{0.90q_t+0.10(1-q_t)}.
\]

For a quiet reading, it is

\[
p_t=\frac{0.10q_t}{0.10q_t+0.90(1-q_t)}.
\]

In each expression, the numerator is the probability of both degradation and the observed reading. The denominator includes both ways to obtain that reading: with a degraded machine or with a normal one. [A27-SENSOR]

Applying these formulas, retaining unrounded values between steps, gives:

| Minute | Reading | Predicted degradation, \(q_t\) | Updated degradation, \(p_t\) |
|---|---|---:|---:|
| 1 | Alarm | 0.1250 | 0.5625 |
| 2 | Quiet | 0.4719 | 0.09031 |
| 3 | Alarm | 0.1177 | 0.5457 |

For example, minute 2 starts from the minute-1 updated probability, 0.5625. The transition gives

\[
q_2=0.05+0.75(0.5625)=0.471875.
\]

Then the quiet reading gives

\[
p_2=\frac{0.10(0.471875)}
{0.10(0.471875)+0.90(0.528125)}
=\frac{151}{1672}\approx0.0903110.
\]

That updated value feeds the next transition. The earlier alarm still influences minute 3 through the evolving state probability; it has neither been discarded nor treated as a reading of an immutable state.

## Where the engineers change the model

The first engineer's 50% calculation is correct for a different model: one fixed hidden state measured three times. It computes

\[
\frac{0.10(0.90\cdot0.10\cdot0.90)}
{0.10(0.90\cdot0.10\cdot0.90)
+0.90(0.10\cdot0.90\cdot0.10)}=0.50.
\]

Here, however, different minutes can have different states. Conditional independence means readings are independent once the **whole state sequence** is specified; it does not mean they all measure one common state. The prediction step accounts for possible state changes. An alarm and a quiet reading therefore cannot simply be cancelled across intervening transitions. [A27-STATE; A27-SENSOR]

Resetting the prior to 0.10 before every reading discards the information carried forward from earlier observations and replaces the stated transition prediction. With 0.10 used directly as each pre-reading probability, an alarm yields 0.50 and a quiet reading yields approximately 0.01220. Those are answers to isolated-reading calculations, not the requested sequential model. [A27-CLAIMS]

## Immediate inspection decisions

Given a current degradation probability \(p\), the expected current-minute costs are:

\[
C_{\text{inspect}}=3,
\qquad
C_{\text{operate}}=20p.
\]

Inspection removes any current degradation, so no additional current-minute degradation loss follows inspection in this model. Inspection has lower expected cost when

\[
3<20p\quad\Longleftrightarrow\quad p>0.15.
\]

At exactly 0.15, either action has the same expected cost. Below it, operating costs less in expectation. [A27-DECISION]

| Decision time | Current probability | Expected cost of operating | Inspection cost | Lower-cost action |
|---|---:|---:|---:|---|
| After minute 2's quiet reading | 0.09031 | 1.806 | 3 | Operate without inspection |
| After minute 3's alarm | 0.5457 | 10.91 | 3 | Inspect |

A probability alone does not specify an action, but the supplied costs and inspection effect make the comparison possible. The manager's distinction between probability and decision is useful; refusing the expected-cost comparison would leave the provided decision model unused.

## Future prediction versus information available now

Under **no intervention**, the minute-4 probability before its reading is

\[
q_4=0.05+0.75p_3
=0.05+0.75(0.5456603425\ldots)
\approx0.4592.
\]

This is a forecast after another opportunity for the state to change. The immediate minute-3 loss depends on the state at minute 3, so its decision uses \(p_3\approx0.5457\), not \(q_4\). The forecast is conditional on no intervention; carrying out the recommended inspection would change that condition. [A27-DECISION]

Using only observations available by the decision time is called **filtering**: minute 2 uses the first alarm and the quiet reading, giving \(P(D_2\mid A_1,Q_2)\). A later reconstruction may also use the minute-3 alarm to estimate the earlier state, \(P(D_2\mid A_1,Q_2,A_3)\); that is retrospective inference, often called smoothing. It can revise what we believe afterward about minute 2, but it cannot describe the information available when the minute-2 action was taken. All probabilities in the table follow the supplied history with no maintenance during the three observations. [A27-OBSERVATIONS; A27-STATE]
