The `return "first"` starts a return, but JavaScript runs the `finally` block before letting the function finish. Inside `finally`, `return "second"` replaces the pending return, so `choose()` returns `"second"` to `console.log`.

If `finally` finished normally, without its own `return` or `throw`, the original `"first"` return would complete. A `return` in `finally` can also override an earlier thrown error, which makes it easy to accidentally hide failures.
